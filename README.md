# Text Analyzer

The Simple Text Analyzer is a lightweight web tool built using HTML, CSS, and JavaScript that allows users to input text and instantly get useful statistics. It analyzes the text to display such as word count, and convert to lowercase and uppercase and check substring. This project highlights real-time input handling, string manipulation, and DOM updates using JavaScript.
